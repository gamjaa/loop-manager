# [R-069] 사용자 결정과 과거 기록 보존

## Context

별도 파일 승인 절차를 제거해도 기존 사용자 결정·감사·작업물은 보존해야 한다. 과거 결정 양식을 현재 실행 권한으로 재해석하지 않는다.

## Requirement

- R-066의 CLI 지침 독립성에 따라 과거 파일 승인 양식을 모델 호출·계획 검증·게시의 특별 계약으로 사용하지 않는다.
- 일반 ExecPlan의 사용자 판단 대기와 User Decision은 사용자를 대신해 작성·해제·변경하지 않는다.
- 저장된 결정·revision·patch·메모·감사는 읽기 호환을 위해 보존한다. 과거 승인 대기의 전환으로 문서나 대상 파일을 자동 수정하지 않는다.

## Acceptance Criteria

- 과거 양식의 존재나 형식 오류만으로 Worker 시작·계획 검증·게시를 중단하지 않는다.
- 사용자 결정과 일반 작업·소유권·검증 경계를 보존한다.
- 과거 결정·감사 내용이 자동 삭제·변경되지 않는다.

## Product Impact

사용자 판단과 과거 기록을 보존하면서 자동 실행의 중복 파일 승인 절차를 없앤다.

## Non-Goals

- 일반 사용자 결정, 작업 범위와 검증·Review·사용자 Merge 조건을 완화하지 않는다.
