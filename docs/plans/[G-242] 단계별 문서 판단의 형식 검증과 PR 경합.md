## Purpose

직접 Merge된 단계별 문서 반영을 유지하면서 문서 판단 결과의 엄격한 의미 검증과 게시 직전 실제 PR 출현 처리를 보완한다. 이미 구현된 PR 전 snapshot·단계 선택·선행 Review는 다시 만들지 않는다.

## Acceptance Criteria

- DOCUMENT_RESULT는 기존 result_normalization helper로 명확한 marker·공백·구분자·다중 줄 JSON을 처리한다. 같은 의미의 형식 차이만으로 모델을 다시 호출하지 않으며 저장 원문과 정규화 결과를 현재 호출 입력에 결합한다.
- 중복 marker·중복 JSON key·상충 판단·누락/빈 evidence·잘못된 relevant/implementation·명시 identity 불일치를 거부한다. json.loads의 마지막 key 값으로 구현 부족을 satisfied로 바꾸지 않는다. 실제 부족한 판단은 기존 교정/보존 경로다.
- snapshot 선정·판단 이후 게시 직전 실제 연결 PR이 나타나면 기존 계획 개정을 게시하지 않는다. proposed/prepared 작업물·실행 이력·동일 PR 연결은 보존하며 추가 범위는 PR 이후 새 ExecPlan 정책으로 인계한다. PR 출현만으로 기존 계획을 PLAN_INPUT_INVALID로 최종 차단하지 않는다. PR 조회 실패는 부재로 해석하지 않는다.
- 원격/후보 변경·PR 경합·중단 재시작에서도 오래된 개정 권한이나 결과로 다음 단계를 시작하지 않는다. 이미 게시한 후보·미완료 보완을 구분하며 실제 원격·현재 ownership/generation을 다시 확인한다. 사용자 결정·다른 실패·session/level과 검증 근거를 보존한다.
- Worker/verify/Reviewer의 최초·교정·재개, 작업 branch 채택, 무관 문서 계속, upper spec 반영과 선행 Review→구현/검증 보완의 기존 동작을 유지한다. 선행 PASS/VERIFY_REQUIRED는 최종 verify/Review 승인이나 게시 token이 아니다.
- ARCHITECTURE의 `### 단계별 원격 문서 반영` 아래에 남은 'Worker·Reviewer 문서 재확인은 현재 ExecPlan 내용 변경에 한정' 설명을 R-082의 연결 Requirement/상위 명세·단계별 입력 증명과 일치시킨다. PRODUCT와 현재 코드에 상반된 제한을 남기지 않는다.

## Implementation

`execution/stage_documents.py`의 parser·prepared PR 재확인과 revision handler의 오류 분류를 기존 형식 helper·PR/catalog/planning 인계 경계에 연결한다. 실제 PR 출현과 형식/관측 오류를 구분하고 보존된 개정 intent를 기존 PR 이후 계획 정책에 넘긴다. 기존 snapshot·checkpoint·읽기 전용 Planner와 자원 예약을 재사용한다. 문서 관련성이 코드 변경의 검증/충돌 복구를 면제하지 않게 한다.

## Validation

- `tests/test_stage_documents.py`, result normalization·incremental planning·execution review/revision fixture의 최소 targeted unit case로 다중 줄/구분자 무재호출, 중복 key/상충 거부, 최초 PR 발견과 두 PR 관측 사이 출현·조회 실패·prepared 재시작을 검사한다.
- 실제 SQLite/handler로 개정 무게시·같은 PR 보존·새 계획 인계와 실패/session 보존을 확인한다. 단계별 Reviewer 선행 PASS/FAIL/VERIFY_REQUIRED 뒤 검증/교정 및 최종 게시 금지 회귀를 유지한다.
- 전체 verify는 직접 구현된 snapshot 실행 이력 보존·작업 branch 채택·후보 무효화·rebase/checkpoint·원격 경쟁을 유지한다. 실제 Git은 기존 게시/rebase 연결 회귀를 재사용하며 새 정책 조합은 관측 mock으로 검사한다. Reviewer는 문서/코드/검증 근거 정합성을 읽기 전용으로 확인한다.
