# 후속 아이디어

## Claude 실환경 후속 점검

공식 문서·mock 기반 개발 후 실제 환경을 사용할 기회가 생기면 아래 항목을 확인한다. 미확인 자체를 개발 차단이나 완전 지원 요구로 취급하지 않으며, mock 결과를 실제 실행 성공으로 기록하지 않는다.

- 실계정 인증·갱신·credential store, 자동 실행 Provider 홈과 개인 설정 분리, 신규·재개·세션 소실 후 호출 호환성.
- OS·CLI·모델/계정 조합의 실제 허용 쓰기, 파일 도구·하위 프로세스 제한, 권한 확대 거부와 오류·중단 처리.
- 실행 중 조직 managed 정책 변경의 적용 순서와 감지 가능성. 별도 hook·polling·외부 격리로 지속 제한을 보장하는 기능은 현재 범위에 포함하지 않는다.
